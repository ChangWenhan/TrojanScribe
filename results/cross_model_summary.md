**How to read this**

- **success** = the victim no longer returns the correct answer (it states a wrong answer, or stops answering).
- **of which really flipped** = the narrower event: the victim now states a specific wrong answer. The rest of the success count is the victim falling silent, which is reported separately because it is not a knowledge rewrite.
- **diagonal** = the same model writing and being attacked; it is the main table's row, repeated here so transfer can be read as a difference against self-attack.
- `-` = that cell has not finished yet.

Consistency: the cross-model blocks in `results/ablation_summary.md` are produced from the same function, so the two files cannot disagree.
